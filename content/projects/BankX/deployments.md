# Deployments

## Overview

BankX is deployed across eight EVM-compatible networks. Each deployment is fully independent with its own contract addresses. The Chainlink oracle consumer contracts must be redeployed per network with the appropriate feed address.

## Deployment Order

Contracts must be deployed in the following order due to circular address dependencies:

```
1. Wrapped native token (WETH / WBNB / WAVAX etc., or use existing)
2. Native/USD Price Consumer (Chainlink)
3. XAG/USD Price Consumer (Chainlink)
4. XSDStablecoin (constructor: name, symbol, pool_amount, genesis_supply, owner, treasury, cap_rate)
5. BankXToken (constructor: treasury, name, pool_amount, symbol, genesis_supply, owner)
6. XSDWETHpool (constructor: owner, reserve0_residue, reserve1_residue)
7. BankXWETHpool (constructor: owner, reserve0_residue, reserve1_residue)
8. CollateralPool (deploy proxy, call initialize())
9. PIDController (deploy proxy, call initialize())
10. RewardManager (deploy proxy, call initialize())
11. Router (deploy proxy, call initialize())
```

### Post-Deployment Configuration

```solidity
// On XSDStablecoin:
XSD.setETHUSDOracle(NATIVE_USD_CONSUMER_ADDRESS);
XSD.setXAGUSDOracle(XAG_USD_CONSUMER_ADDRESS);
XSD.setRouterAddress(ROUTER_ADDRESS);
XSD.setXSDEthPool(XSDWETH_POOL_ADDRESS);
XSD.setBankXEthPool(BANKXWETH_POOL_ADDRESS);
XSD.setCollateralEthPool(COLLATERAL_POOL_ADDRESS);
XSD.addPool(COLLATERAL_POOL_ADDRESS);
XSD.addPool(REWARD_MANAGER_ADDRESS);

// On BankXToken:
BankX.setXSDAddress(XSD_ADDRESS);
BankX.setPool(BANKXWETH_POOL_ADDRESS);
BankX.setRouterAddress(ROUTER_ADDRESS);

// On XSDWETHpool:
XSDWETHpool.initialize(XSD_ADDRESS, WETH_ADDRESS, BANKX_ADDRESS, PID_ADDRESS, COLLATERAL_POOL_ADDRESS, ROUTER_ADDRESS);

// On BankXWETHpool:
BankXWETHpool.initialize(BANKX_ADDRESS, WETH_ADDRESS, XSD_ADDRESS, PID_ADDRESS, ROUTER_ADDRESS);

// On PIDController:
PID.setRewardManagerAddress(REWARD_MANAGER_ADDRESS);
PID.setBankXNFTAddress(BANKX_NFT_ADDRESS);
PID.setCDAddress(CD_ADDRESS);
```
